# User guide

Create campaigns to group related content and limits. Upload private media with useful alt text, store approved captions, then use Composer to choose destinations and time. Queue shows each destination independently; published jobs are immutable. Retry only failures after correcting their cause.

For Pages, connect Meta and monitor token status. For Groups, add URLs manually and record rules, promotion permission, approval requirements, and exclusions. Confirmation mode is recommended. Never target a Group where posting is not allowed.

Devices turn offline after the configured heartbeat timeout. Pause before maintenance and revoke lost devices. Analytics are internal publishing statistics unless explicitly labelled Meta engagement. Audit logs preserve schedule, connection, device, and retry actions.

For export, an owner should export organisation tables and the organisation's Storage prefix through a trusted server process. For deletion, confirm all members understand the impact, pause publishing, revoke devices and Meta connections, back up if required, then run the documented server-only deletion procedure. Never delete a tenant by exposing the service-role key to the browser.
